# Security policy

## Reporting vulnerabilities

Please do not publish exploitation details, credentials or private infrastructure data in public GitHub issues.

If GitHub private vulnerability reporting is enabled on this repository, use **Security → Report a vulnerability**. Otherwise contact the repository maintainer through a private channel listed on their GitHub profile. Avoid sharing secrets in unencrypted messages.

## Scope

This is a documentation and example repository, not a maintained production container image or security product. Guidance is best-effort and must be evaluated against your organization's threat model and Docker version.

## Responsible contribution

- Submit corrections with reproducible, authorized test cases.
- Never include tokens, passwords, customer data or actual malware samples.
- Replace leaked credentials immediately and remove them from Git history with an approved procedure where necessary.
